# Swap System

Root folder for swap system with SDK on Blockchain VM. The main goal is to provide digital EUR swaps to other digital currencies via smart contracts.

## Project Structure

```
.
├── orchestrator/     # Backend orchestrator (NestJS + Fastify + PostgreSQL)
└── README.md
```

## Orchestrator

The backend orchestrator is a NestJS application with Fastify adapter and PostgreSQL. See [orchestrator/README.md](./orchestrator/README.md) for details.
